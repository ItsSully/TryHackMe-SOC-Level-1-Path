# Core SOC Solutions

**TryHackMe SOC Level 1 — Module 3**

**Status:** ✅ Completed

## Overview

This module introduced core technologies used within Security Operations Centres, focusing on **Endpoint Detection and Response (EDR), Security Information and Event Management (SIEM), and Security Orchestration, Automation and Response (SOAR)**.

I also explored **Splunk** and the **Elastic Stack (ELK)** as platforms used by SOC analysts for log investigations.

## Topics Covered

### Endpoint Detection and Response (EDR)

I learned the fundamentals of **EDR** and explored its features and how it operates.

EDR focuses on security monitoring and detection at the endpoint level, helping security teams identify and investigate potentially malicious activity occurring on devices.

**Skill developed:** Understanding endpoint security monitoring and detection.

### Security Information and Event Management (SIEM)

I learned the fundamentals of **SIEM** and its functionality within a SOC environment.

SIEM platforms are used by security analysts to work with security-related logs and investigate events across an environment.

**Skill developed:** Understanding SIEM functionality and its role in security investigations.

### Splunk

I explored the basics of **Splunk** and how SOC analysts can use it for log investigations.

This builds on my earlier experience using Splunk within the SOC Simulator during the phishing scenario.

**Skill developed:** Introduction to Splunk-based log investigation.

### Elastic Stack (ELK)

I learned the fundamentals of the **Elastic Stack (ELK)** and how SOC analysts can use it for log investigations.

This provided exposure to an alternative platform for working with and investigating security data.

**Skill developed:** Introduction to Elastic Stack-based log investigation.

### Security Orchestration, Automation and Response (SOAR)

I learned the concepts and methodology behind **Security Orchestration, Automation and Response (SOAR)**.

SOAR focuses on coordinating and automating security processes to support incident response and security operations.

**Skill developed:** Understanding security automation and orchestration.

## Key Takeaways

* EDR provides a way of monitoring and detecting security activity at endpoints.
* SIEM is an important technology used by SOC analysts when working with security logs and events.
* Splunk can be used to investigate logs within a SOC environment.
* The Elastic Stack provides another platform for security data and log investigation.
* SOAR focuses on orchestration and automation within security operations.
* SOC analysts may work with multiple security solutions depending on the organisation and its environment.
