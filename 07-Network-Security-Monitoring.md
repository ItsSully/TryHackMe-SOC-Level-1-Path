# Network Security Monitoring

**TryHackMe SOC Level 1 — Module 7**

**Status:** ✅ Completed

## Overview

This module focused on network security monitoring and the detection of network-based attacks.

I learned how security teams monitor network activity, detect network discovery and data exfiltration attempts, identify Man-in-the-Middle attacks and use Intrusion Detection Systems (IDS) to detect suspicious activity.

The module also introduced **Snort** and its use in detecting threats and analysing network traffic.

---

## Topics Covered

### Network Security Essentials

I learned the key fundamentals of network security and how monitoring can be used to identify and respond to adversarial activity.

**Skill developed:** Understanding network security monitoring and defensive controls.

### Network Discovery Detection

I learned how attackers discover assets and services within a network and how this activity can be detected through network monitoring.

**Skill developed:** Network discovery and reconnaissance detection.

### Data Exfiltration Detection

I learned how data exfiltration can occur through different network channels and how monitoring can help identify potential attempts to remove data from an environment.

**Skill developed:** Data exfiltration detection and network monitoring.

### Man-in-the-Middle Detection

I learned what Man-in-the-Middle (MITM) attacks are and how their indicators can appear within network traffic.

**Skill developed:** MITM attack detection and network traffic analysis.

### IDS Fundamentals

I learned the fundamentals of **Intrusion Detection Systems (IDS)** and how they can be used to identify potentially malicious network activity.

I was also introduced to **Snort** as an example of an IDS.

**Skill developed:** Understanding IDS concepts and network-based threat detection.

### Snort

I learned how **Snort** can be used to detect threats, analyse network traffic and identify anomalies.

**Skill developed:** Network intrusion detection using Snort.

---

## Key Takeaways

- Network monitoring provides visibility into potentially malicious activity.
- Network discovery activity can provide indicators of reconnaissance.
- Monitoring network traffic can help identify potential data exfiltration.
- MITM attacks can leave identifiable footprints within network traffic.
- IDS solutions can help detect suspicious network activity.
- Snort can be used to analyse traffic and detect potential threats.
