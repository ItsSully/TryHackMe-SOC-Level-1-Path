# SOC Team Internals

**TryHackMe SOC Level 1 — Module 2**

**Status:** ✅ Completed

## Overview

This module focused on the practical responsibilities of a Level 1 SOC analyst, including alert triage, alert reporting, the use of workbooks and lookups, SOC performance metrics, and an introduction to phishing analysis.

## Topics Covered

### SOC L1 Alert Triage

I learned about the role of alert triage within a SOC and the importance of using a systematic approach when assessing security alerts.

A structured triage process helps analysts efficiently evaluate alerts and determine which events require further investigation or escalation.

**Skill developed:** Alert triage and prioritisation.

### SOC L1 Alert Reporting

I learned how SOC analysts should communicate information about higher-risk alerts through appropriate reporting and escalation.

Effective reporting allows relevant information to be communicated clearly so that appropriate teams can take further action.

**Skill developed:** Security alert reporting, communication and escalation.

### SOC Workbooks & Lookups

I explored the use of organisational resources such as workbooks and lookups to support and structure the alert triage process.

These resources can help analysts consistently assess alerts and simplify the investigation process.

**Skill developed:** Using structured resources to support SOC investigations.

### SOC Metrics & Objectives

I learned about metrics used to evaluate the effectiveness of SOC operations and ways these metrics can be improved.

Understanding SOC metrics provides insight into how effectively a security team is handling and responding to alerts.

**Skill developed:** Understanding SOC performance measurement.

### Introduction to Phishing

I completed my first scenario using the **SOC Simulator** and was introduced to analysing phishing-related security events.

This provided an opportunity to apply SOC concepts within a simulated investigation environment.

**Skill developed:** Phishing analysis and security alert investigation.

## Key Takeaways

* Alert triage is an important responsibility of an L1 SOC analyst.
* A systematic approach helps analysts assess alerts efficiently.
* High-risk alerts may need to be reported and escalated appropriately.
* Workbooks and lookups can provide structured information to support investigations.
* SOC metrics can be used to measure and improve the effectiveness of security operations.
* Phishing is an important attack type that SOC analysts may need to investigate.
* Simulated environments can provide practical experience with SOC workflows.

## Skills Developed

* Alert triage
* Alert prioritisation
* Security alert reporting
* Escalation and communication
* Use of SOC workbooks and lookups
* Understanding SOC metrics
* Phishing analysis
* Practical SOC investigation

## Reflection

This module gave me a better understanding of the operational side of working as an L1 SOC analyst. In particular, learning about alert triage and reporting helped me understand that SOC analysis is not only about identifying suspicious activity, but also about systematically assessing alerts and communicating findings so that appropriate action can be taken.
